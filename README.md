# Atividade Prática – Rotas com Node.js e Express

Projeto desenvolvido para praticar a criação de rotas utilizando Node.js e Express.

## Rotas disponíveis

- `/` — Bem-vindo ao site da Marvel e DC!
- `/marvel` — Este é o universo de heróis da Marvel.
- `/dc` — Este é o universo de heróis da DC.

## Tecnologias utilizadas

- Node.js
- Express

## Como executar o projeto

1. Instale o Node.js (versão LTS recomendada).
2. Abra um terminal nesta pasta.
3. Execute `npm install`.
4. Execute `npm start`.
5. Acesse os endereços abaixo no navegador:
   - http://localhost:3000/
   - http://localhost:3000/marvel
   - http://localhost:3000/dc

A pasta `node_modules` é criada automaticamente pelo `npm install` e não deve ser enviada ao GitHub.
